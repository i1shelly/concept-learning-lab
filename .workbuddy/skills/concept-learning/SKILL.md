# 概念学习资料生成 Skill（concept-learning）

把"查证 → 理解 → 表达 → 自测"的学习流程固化为可复用工具：给它任何概念名，
它都会以相同的严谨流程产出一份结构化学习页，而不是随口解释一段。

## 适用场景

- 学到一个新概念，想要系统化、结构化的理解，而不是碎片化快答
- 整理课程知识点，需要关键事实可核对、来源可核查的学习资料
- 为后续复习沉淀自测题
- **不适用**：只需一句话定义的快问快答（直接回答即可，无需启动本 Skill）

## 输入信息

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| concept | 是 | 概念名称，任意学科领域，如"贝叶斯定理""梯度下降""Agent" | — |
| depth | 否 | 入门 / 进阶 | 入门 |
| audience | 否 | 面向的读者，如"大一新生""跨专业初学者" | 初学者 |

## 生成步骤（按序执行，不得跳步）

1. **定位概念**：确认概念所属领域与边界，判断是否与常见概念重名，必要时先做一次快速检索
2. **查证来源（硬性要求）**：用网络搜索检索权威来源，优先级：官方文档 > 原始论文/技术报告 > 权威工程师博客 > 教科书/百科。**至少收集 3 个可公开访问的来源，逐个确认真实存在；禁止凭记忆编造链接**
3. **拟定学习目标**：写 3 条"学完后你应该能……"的目标
4. **提炼核心问题**：2~3 个初学者最可能困惑的问题，资料正文必须正面回答它们
5. **撰写个人解释**：用第一人称、自己的话写一段比喻式解释；禁止整段照搬来源或 AI 对话原文
6. **梳理核心机制**：概念的组成部件与运作方式，多用列表和表格，少用大段文字
7. **设计应用场景**：一个具体、贴近学习者经验的真实场景，说清概念在其中如何起作用
8. **概念辨析**：列出 2~4 个易混淆概念或常见误解，以及使用边界（什么时候不适用、会失效）
9. **编写自测题**：3~5 题（选择/判断/简答），全部附参考答案，答案折叠隐藏
10. **组装 HTML**：按"输出结构"生成独立 HTML 文件（内联 CSS、无外部依赖、UTF-8），文件名用概念英文名 slug
11. **执行自检**：对照"自检要求"逐项检查，不通过则修正后重检，全部通过才交付

## 输出结构

输出文件：`learning-materials/<concept-slug>.html`（如 `learning-materials/agent.html`）

页面模块（固定顺序，共 9 个）：

| # | 模块 | 内容要点 |
|---|------|----------|
| 1 | 页头 | 概念名 + 一句话定位 + 生成信息（日期/作者/生成方式） |
| 2 | 学习目标 | 3 条，"学完后你能……"句式 |
| 3 | 核心问题 | 2~3 个，正文必须逐条回应 |
| 4 | 我的解释 | 第一人称个人化解释，含一个贴切的比喻 |
| 5 | 核心机制与组成 | 部件 + 运作方式，列表/表格呈现 |
| 6 | 应用场景 | 一个具体场景，说清概念如何起作用 |
| 7 | 概念辨析与边界 | 易混淆点 + 使用边界 |
| 8 | 自测 | 3~5 题，答案折叠 |
| 9 | 参考来源 | ≥3 个已验证链接，标注类型与推荐阅读顺序 |

## 资料来源要求（不可妥协）

- **数量**：每份资料至少 3 个来源
- **质量优先级**：官方文档 > 原始论文 > 权威工程博客 > 教材/百科
- **真实性**：所有链接必须经搜索或访问验证确实存在；宁可少列，不可编造
- **标注**：注明来源类型（官方文档/论文/博客）与一句话推荐理由
- **一致性**：资料中的关键事实（数字、机制描述）必须与来源一致，不得夸大或过时
- **语言**：中文撰写；英文来源需在推荐理由中说明阅读价值

## 自检要求（生成后逐项打钩）

- [ ] 九个模块齐全、顺序正确
- [ ] "我的解释"为第一人称，未整段照搬任何来源
- [ ] 每个核心问题都在正文中得到回答
- [ ] 所有来源链接已逐一验证可访问
- [ ] 关键事实与来源核对一致
- [ ] 自测题均附参考答案
- [ ] HTML 无外部依赖，浏览器双击即可打开，中文显示正常
- [ ] 文件已保存到 learning-materials/ 且命名规范

## 使用示例

- "用 concept-learning 学习『大模型的上下文』" → `learning-materials/llm-context.html`
- "帮我用 concept-learning 整理『梯度下降』，进阶难度" → `learning-materials/gradient-descent.html`
- "用 concept-learning 学习『强化学习』，读者是大一新生" → `learning-materials/reinforcement-learning.html`

## 设计说明

本 Skill 的学习设计遵循四条思路：**检索验证**防幻觉（先查证再动笔）、
**固定结构**防遗漏（九模块模板）、**输出倒逼输入**（个人解释必须自己组织语言）、
**自测巩固**防"看懂了的错觉"（合上资料也能答上来才算学会）。
